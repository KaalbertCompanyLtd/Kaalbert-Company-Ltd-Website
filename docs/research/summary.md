## What ties all of this together

Every recommendation in this table follows one consistent rule, stated first in
`runtime-framework-and-admin.md` after the WordPress option was explicitly rejected:
**packages and external APIs are used as building blocks inside code the team writes and
owns; no product (a CMS, a booking widget, a hosted checkout page, an identity service) is
allowed to own the admin UI, the data model, or the routes.** Infrastructure — hosting,
database, CDN, object storage — is treated differently from that rule on purpose: using a
managed platform to run custom code is not the same as depending on a pre-built product to
define what that code does, in the same way building a custom application doesn't require
running your own data centre.
